# 🚀 Smart News Enhancer

## 📌 Project Overview
Smart News Enhancer is a static web application designed to present news content in an enhanced and user-friendly format. The project focuses on clean UI, responsiveness, and real-world deployment using cloud infrastructure.

---

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Server: Nginx  
- Cloud Platform: AWS EC2  

---

## ☁️ Deployment
This project is deployed on an AWS EC2 instance using Nginx as the web server.

- Configured EC2 instance (Amazon Linux)
- Installed and configured Nginx
- Hosted static website in /usr/share/nginx/html
- Accessed via public IP over HTTP
